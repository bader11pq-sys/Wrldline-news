تسجيل دخول المحرر

استخدم حساب محرر مصرحاً به. لا توجد كلمة مرور مشتركة أو مخزنة داخل ملفات الموقع.

يمكنك الدخول برابط لمرة واحدة دون الحاجة إلى تذكر كلمة المرور.

تعيين كلمة مرور جديدة

أدخل كلمة مرور جديدة لحسابك. ستبقى داخل موقع WRLDLINE ولن يتم تحويلك إلى localhost.

الحساب غير مخوّل للتحرير

يلزم منح حساب المحرر دوراً موثوقاً من Supabase Dashboard عبر Authentication → Users → المستخدم → Raw App Metadata وإضافة {"role":"admin"}، ثم تسجيل الخروج والدخول مجدداً. لا تستخدم User Metadata لهذا الغرض.

إدارة الأخبار

تخضع عمليات النشر والتعديل والحذف لسياسات Row Level Security في Supabase. لا تمنح صلاحيات الكتابة للمستخدمين المجهولين.

فحص مزودات الذكاء الاصطناعي

اختبار اتصال ومصادقة وتوليد/ترجمة فعلية من الخادم دون كشف مفاتيح API.
يشمل الاختبار Gemini وGroq وNVIDIA وOpenRouter وGonka وDeepL. الاختبار يرسل طلبًا قصيرًا حقيقيًا لكل مزود مُعدّ، وقد يستهلك قدرًا ضئيلًا من الحصة.
اضغط «فحص جميع المزودات» لبدء الاختبار.
يمكنك كتابة النص على عدة فقرات، وستظهر فواصل الأسطر في صفحة القراءة.
الصور حتى 20 ميغابايت، ومقاطع الفيديو حتى 100 ميغابايت.

غرفة المراجعة

يعمل التصنيف الذكي تلقائياً في الخلفية بعد وصول الأخبار. هذا الزر مخصص لإعادة محاولة الأخبار المتعثرة أو المعلقة فقط. يتطلب ذلك ضبط مفاتيح الخدمة الموضحة في AI_SETUP.md. النتائج منخفضة الثقة تظهر للمراجعة، والتصنيف لا يقيس صحة الخبر.
