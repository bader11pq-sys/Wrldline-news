# قائمة الامتثال الأولية — WRLDLINE NEWS

**التاريخ:** 14 نوفمبر 2026  
**الغرض:** قائمة عمل أولية قبل التقديم أو البيع أو إطلاق الشراكات المدفوعة.  
**تنبيه:** هذه ليست استشارة قانونية. العناصر الموسومة «مراجعة قانونية» تحتاج محاميًا مرخصًا في نطاق النشاط والاختصاص القضائي.

## 1. الحقوق والمحتوى

| العنصر | الحالة الحالية | المطلوب / ملاحظة |
|---|---|---|
| نسبة الأخبار إلى المصدر | منفذ: اسم المصدر + رابط أصلي + تاريخ نشر في البطاقة والمودال | التحقق الدوري من صحة خرائط المصادر، خصوصًا الأسماء التي لا تطابق النطاق |
| عدم نسخ المقال كاملًا | منفذ: الموقع يعرض ملخصًا/ترجمة ورابطًا للمصدر | مراجعة أي حقل `summary` طويل أو منسوخ حرفيًا من المصدر |
| الصور والشعارات | منفذ جزئيًا: تُعرض صور المصادر/المزودين مع النسب | **مراجعة قانونية:** لا توجد تراخيص موثقة لكل صورة. يلزم فحص عينة، وإزالة ما لا يملك الموقع حق استخدامه، أو استبداله بصور مرخصة |
| وكالات الأنباء | منفذ جزئيًا: روابط ومقتطفات فقط | **مراجعة قانونية:** مراجعة شروط RSS/الاشتراك مع كل وكالة، ومنع إعادة النشر الكاملة |
| المحتوى المدعوم | منفذ: شارة «محتوى مدعوم»، اسم الراعي، رابط الراعي عند توفره | **مراجعة قانونية:** عقد رعاية يوضح الإفصاح، حدود التحرير، الاستخدام، الإعفاءات، والضرائب |
| الإبلاغ عن حقوق النشر | منفذ: نموذج تواصل بموضوع «حقوق النشر» | إضافة مسار إشعار/إزالة موثق، ومدة استجابة، وسجل قرارات |
| المحتوى المضلل/المكرر | منفذ جزئيًا: حجب 121 عنوان RSS عام إلى `review`، ومنع التكرار في العرض | **تحريري:** مراجعة بشرية للحالات المحجوبة، وتحديث السياسة عند وجود سحب/تصحيح فعلي |

## 2. الخصوصية والبيانات

| العنصر | الحالة الحالية | المطلوب / ملاحظة |
|---|---|---|
| سياسة خصوصية واضحة | منشورة في `privacy.html` وتغطي الحساب والنماذج والقياس والتخزين المحلي والمزودين والحقوق | **مراجعة قانونية:** اعتماد الصيغة النهائية، إضافة الكيان القانوني والعنوان وقناة خصوصية فعلية |
| ملفات الارتباط/التخزين | لا تستخدم ملفات ارتباط إعلانية. تستخدم `localStorage` للغة والمظهر والمحفوظات والموافقة، و`sessionStorage` لمعرّف جلسة عشوائي | إضافة جدول مفاتيح التخزين ومدة الاحتفاظ؛ مراجعة سنوية |
| Google Analytics 4 | غير مفعّل افتراضيًا؛ لا يُحمّل إلا عند وضع معرّف في `analytics-config.js` وموافقة الزائر | **مراجعة قانونية/تشغيلية:** إنشاء Property، ضبط retention، Consent Mode، DPA، والتحقق من عدم إرسال PII |
| مزودو المعالجة | Supabase (قاعدة/مصادقة)، Stripe (دفع عند التفعيل)، TradingView (أدوات أسواق)، مزودو بيانات السوق | توثيق DPAs/شروط المعالجة، وتقييم النقل الدولي، وتحديث قائمة المزودين |
| طلبات الوصول/الحذف | نموذج تواصل بموضوع «طلب خصوصية أو حذف بيانات» | إنشاء إجراء تحقق من الهوية، سجل طلبات، ومدة استجابة موثقة |
| الاحتفاظ | مذكور مبدئيًا في السياسة | تحديد جدول فعلي لكل نوع بيانات، وربطه بسياسة الحذف الآلي |
| وصول المحررين إلى الرسائل | منفذ: RLS تسمح بالقراءة لأدوار editor/admin فقط | إضافة صندوق رسائل داخل لوحة الإدارة بدل الاعتماد على Supabase Dashboard |
| اختراق البيانات | لا يوجد إجراء منشور | **مراجعة قانونية:** خطة إشعار، مسؤولية، ومهل نظامية حسب الاختصاص |
| الأطفال | مذكور أن الخدمة ليست للأطفال دون 16 | التحقق من التوافق مع القانون المحلي قبل الإطلاق التجاري |

## 3. الشروط والاشتراكات

| العنصر | الحالة الحالية | المطلوب / ملاحظة |
|---|---|---|
| شروط استخدام | منشورة في `terms.html` | **مراجعة قانونية:** الكيان، القانون الحاكم، الاختصاص، حدود المسؤولية، وحقوق المستهلك الإلزامية |
| الاشتراك المدفوع | صفحة حساب وStripe عند التفعيل | إضافة سياسة استرداد وإلغاء وتجديد واضحة قبل الدفع، ومراجعة الضرائب/VAT |

| النشر الإلكتروني | الموقع ينشر محتوى إخباريًا | **مراجعة قانونية:** متطلبات التسجيل/الترخيص أو الإخطار المحلي إن انطبقت، وسياسة المحتوى |
| الملكية الفكرية للموقع | اسم وتصميم ومحتوى أصلي | تسجيل العلامة/حقوق التصميم حسب الحاجة، ومراجعة عقود المطورين والمساهمين |

## 4. القياس والامتثال التشغيلي

| العنصر | الحالة الحالية | المطلوب / ملاحظة |
|---|---|---|
| أحداث القياس | `page_view`, `view_article`, `outbound_source_click`, `search`, `market_view`, `newsletter_signup`, `sponsor_contact`, `plus_interest` | إبقاء القائمة محدودة؛ مراجعة أي حدث جديد قبل إضافته |
| عدم إرسال PII | منفذ: تنقية المفاتيح والقيم، حجب البريد/الهاتف، عدم إرسال نص البحث | اختبار دوري جديد لكل تغيير في الأحداث |
| استبعاد الإدارة/الاختبار | منفذ: `admin.html` لا يحمّل طبقة القياس؛ يمكن إضافة فلتر بيئة اختبار عند تفعيل GA4 | توثيق عنوان IP/شبكة الاختبار أو معرّف بيئة لاستبعادها من GA4 |
| الموافقة | لافتة قبل القياس، ورفض يمنع الإرسال | مراجعة صياغة الموافقة، وإثبات السجل، وإمكانية السحب |
| تقرير الاختبار | في `docs/analytics-test-report.md` | إعادة الاختبار بعد ربط GA4 الفعلي |

## 5. العناصر غير المحسومة — يجب حلها قبل التقديم أو البيع

1. **الكيان القانوني:** الاسم الرسمي، السجل التجاري، العنوان، ممثل الخصوصية/الامتثال. (حرج)
2. **الاختصاص والقانون الحاكم:** تحديد الدولة والمحاكم وآلية فض النزاع في الشروط. (حرج)
3. **تراخيص الصور ووكالات الأنباء:** قائمة مصادر/تراخيص موثقة، وإزالة غير المرخص. (حرج)
4. **DPA مع Supabase/Stripe/TradingView/GA4:** توقيع أو اعتماد الشروط المعالجة، وتقييم النقل الدولي. (مرتفع)
5. **سياسة الاحتفاظ والحذف:** جدول لكل جدول بيانات، وآلية تنفيذ. (مرتفع)
6. **إجراءات حقوق أصحاب البيانات:** تحقق الهوية، سجل الطلبات، ومهل الاستجابة. (مرتفع)
7. **سياسة الاسترداد والضرائب:** قبل تفعيل WRLDLINE PLUS. (مرتفع)
8. **عقود الرعاية والإعلان:** إفصاح، ملكية المحتوى، إخلاء مسؤولية، ودفع. (مرتفع)
9. **الامتثال الإعلاني/النشر المحلي:** رأي محامٍ محلي قبل التسويق المدفوع. (مرتفع)

10. **خطة اختراق البيانات:** مسؤول، قنوات، ومهل إشعار. (متوسط)

11. **مراجعة الترجمة البشرية:** 30 عينة موثقة، وبعضها يحتاج إعادة ترجمة قبل النشر. (مرتفع تحريريًا)

12. **سجل التصحيحات الفعلي:** لا يكفي وجود السياسة؛ يلزم سجل عام للتصحيحات والسحب. (متوسط)
