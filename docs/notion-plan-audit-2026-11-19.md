## 2. ملخص تنفيذي

WRLDLINE ليس في مرحلة «تنفيذ جميع الخطط دفعة واحدة». الخطط نفسها تحدد تسلسلاً: التدقيق، تثبيت الأساس، بناء ملف الحدث، اختبار قيمة المستخدم، ثم اختبار الإيرادات. كما تنص وثائق Notion على أن الرسائل لم تُرسل، ولا يوجد عميل أو شراء مؤكد، وأن السعر 2,000 ريال فرضية اختبار داخلية.

**القرار التشغيلي:** نُفذت الآن أعمال التدقيق والتوثيق فقط. لا يجوز اعتبار التواصل مع الشركات أو إطلاق الدفع أو تفعيل البريد/Push أو تطبيق migrations إنتاجية أو النشر نجاحاً دون اختبار وموافقة مناسبة.

## 5. ما يمكن اعتباره منفذاً الآن

هذه البنود منخفضة المخاطر ويمكن تنفيذها على فرع تطوير منفصل بعد اعتماد نطاقها:

1. تثبيت اعتماديات الاختبارات الناقصة وتشغيل المجموعة كاملة.
2. استكمال تقرير خريطة الصفحات والبيانات والتكاملات.
3. إضافة اختبارات/أدوات تحقق لجودة الأخبار الجديدة: المصدر، الملخص، وقت النشر، وحالة الترجمة.
4. إعداد نموذج بيانات/واجهة داخلية لملف الحدث الحي دون ربطه بالنشر العام قبل المراجعة.
5. إصلاحات كود صغيرة ذات قبول واضح بعد تحديد الملف والمشكلة، مع عدم تنفيذ migration إنتاجية تلقائياً.
6. إعداد نسخة PDF داخلية من موجز B2B بعد فحص المصادر والحقوق، من دون إرسالها.

## 6. ما يتطلب موافقة أو وصولاً خارجياً

لا أنفذه تلقائياً رغم وروده في الخطط:

- إرسال رسائل أو إجراء اتصالات إلى Howden أو GAC أو Asyad أو KOTC أو Bahri.
- إنشاء مواعيد مقابلات أو مشاركة ملفات مع جهات خارجية.
- دمج فرع/PR أو نشر نسخة جديدة على GitHub Pages/Cloudflare.
- تنفيذ migration أو تغيير RLS أو صلاحيات Supabase في الإنتاج.
- تفعيل بريد أو VAPID أو إرسال Push.
- تشغيل اختبار دفع Live أو تغيير أسعار/صلاحيات الاشتراك.
- تفعيل مزود AI أو شراء حصة/خدمة مدفوعة.
- استعادة نسخة إنتاج أو التعامل مع بيانات العملاء.
