# تنفيذ حزمة خطة WRLDLINE — 19 نوفمبر 2026

## النطاق

نُفذت ستة بنود منخفضة المخاطر على فرع التطوير `audit/notion-plan-execution-2026-11-19`. لم تُعدّل بيانات الإنتاج ولم تُنفذ migration أو نشر.

## البنود المنفذة

1. **بوابة جودة RSS:** الخبر الذي يفتقد ملخصاً يبقى `review` ولا يدخل الإسقاط العام المنشور. طُبق ذلك في `bot-ingest.js` ودالة `wrldline-news-ingest`.
2. **شفافية دليل المصادر:** يعرض دليل المصادر نافذة الرصد، وقت آخر نشر مرصود، وحالة الحداثة، ويستخدم «المصدر غير متاح» بدلاً من اسم مختلق.
3. **اتساق PLUS:** لا تُعرض الحالة `trialing` كعضوية مدفوعة نشطة، ولا تظهر بوابة الفوترة إلا لاشتراك `active`.
4. **جاهزية النشرة:** عند فشل فحص جاهزية البريد يظهر سبب واضح، ويبقى زر الاشتراك معطلاً ولا يُحفظ البريد.
5. **شفافية الأسواق:** بطاقات الأسعار المباشرة تعرض مزود API ونوع السعر ووقت المزود بعنصر `time`.
6. **اختبار حماية الاستيراد:** أضيف اختبار يثبت أن عنصر RSS بلا ملخص يُحوّل للمراجعة، مع الحفاظ على اختبارات التصنيف الحالية.

## معيار القبول

- لا يعرض الموقع خبراً ناقص الملخص كخبر منشور من مسار RSS.
- لا يوحي دليل المصادر أو PLUS أو النشرة بوجود حالة غير مثبتة.
- لا تعرض بطاقة السوق وقتاً غير موصوف أو مزوداً غير معروف.
- تمر اختبارات JavaScript وTypeScript/البنية ذات الصلة قبل أي نشر.
