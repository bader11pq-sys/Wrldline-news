# WRLDLINE — خريطة المنتج والصفحات والبيانات

التاريخ: 19 نوفمبر 2026
الغرض: مرجع واحد لما هو منشور، وما يعمل فعلاً، وما يحتاج إثباتاً. لا يعتمد على أسماء الملفات وحدها.

## 2. مسار البيانات

```text
مصادر RSS
  → مستورد محلي (bot-ingest.js) أو دالة Supabase المجدولة
  → جدول articles (عنوان، ملخص، مصدر، لغة، تصنيف، حالة تحريرية)
  → تصنيف/ترجمة (AI + قواعد)
  → نشر عام (editorial_status = published)
  → RPC عامة → الواجهة
  → ملفات الأحداث (JSON مُنسق يدوياً بمصادر) → صفحات ثابتة
```

نقاط المراقبة: عدد العناصر المستلمة، المرفوضة، المحوّلة إلى مراجعة، وفشل التصنيف أو الترجمة. لا يكفي وجود جدول أو دالة لإثبات أن المسار يعمل.

## 3. حالة المكونات

| المكوّن | الحالة | ما ينقص |
|---|---|---|
| استيراد RSS | يعمل بكثافة عالية | ضبط الحجم والجودة؛ 57,033 خبراً في 7 أيام |
| بوابة الملخص الناقص | يعمل | منشورة في الكود؛ تحتاج نشر الدالة المجدولة |
| بوابة الملخص المكرر | يعمل في الكود | 977 خبراً قديماً لم يُعد تصنيفها |
| التصنيف | جزئي | 19,452 غير مصنف و24,980 «world» في 7 أيام |
| الترجمة | جزئي | عناوين إنجليزية تظهر في الموجز |
| ملفات الأحداث | يعمل | التحرير يدوي عبر JSON؛ لا لوحة إدارة |
| البحث في الملفات | يعمل | بحث نصي بسيط، لا فهرس خادم |
| ربط الأخبار بالملفات | يعمل | مطابقة كلمات مفتاحية من آخر 80 خبراً |
| النشرة | جزئي | الإرسال يعتمد على مزود غير متحقق |
| PLUS والدفع | غير متحقق | لا مفاتيح Stripe، لا اختبار webhooks |
| الأسواق | جزئي | مصدر السعر ووقته معروضان؛ لا تأكيد لحظية |
| الإدارة | غير متحقق | يحتاج فحص صلاحيات وأدوات تحرير |
| التحليلات | جزئي | أحداث واجهة موجودة؛ لا قياس تحويل موثق |

## 4. ما يعنيه ذلك تجارياً

- المنتج المركزي (ملفات الأحداث) أصبح موجوداً وقابلاً للبيع كعينة B2B، لكنه يحتاج إيقاع تحديث أسبوعي.
- لا يمكن بيع PLUS بثقة قبل إثبات أن المستخدم يعود إلى الملفات ويستخدمها.
- لا يمكن اعتبار النشرة قناة عودة قبل التحقق من الإرسال والتأكيد.
- الأولوية ليست ميزة جديدة، بل رفع نسبة المحتوى الذي يستحق الواجهة.

## 5. قواعد ثابتة

- لا حجب للأخبار العامة خلف PLUS.
- لا سعر سوق بلا مزود ووقت ونوع سعر.
- لا عبارة في ملف حدث بلا مصدر وحالة تحقق.
- لا تحديث جماعي للبيانات دون نسخة احتياطية وخطة تراجع.
- لا ادعاء نجاح دفع أو نشر أو اختبار لم يحدث.
