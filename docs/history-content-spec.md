# WRLDLINE History — مواصفة المحتوى والبيانات

## الهدف
بناء مرجع تاريخي عربي رصين، قابل للاستشهاد، يغطي الحضارات والدول والتحولات الكبرى، بأسلوب تحليلي لا احتفالي. المحتوى تعليمي/مرجعي، وليس دعاية وطنية.

## قواعد التحرير
- الفصحى المعاصرة، جمل واضحة، بلا مبالغات أو صفات خطابية.
- الدقة قبل الإسهاب. عند اختلاف التواريخ أو التقديرات، اكتب «نحو» أو «تقريباً» واذكر الخلاف في `debates`.
- لا تختلق أرقاماً أو اقتباسات أو أسماء مصادر. استخدم مصادر حقيقية معروفة (Britannica, UNESCO, Library of Congress, Met Museum, Europeana, الأرشيف الوطني المعني، Yale Law, Our World in Data).
- لا تُسقط دور المرأة والمجتمعات المهمشة والاقتصاد والبيئة. تجنّب السرد القائم على الملوك والحروب فقط.
- لا تستخدم عبارات مثل «أعظم أمة» أو «مجيدة». استخدم «أثرت»، «شكّلت»، «أسهمت».
- كل نص عربي بعلامات ترقيم عربية مناسبة، وبلا إيموجي داخل النصوص (الإيموجي فقط في حقل flag).
- لا تكرر فقرات أو جمل بين الملفات.

## معايير الجودة
- `summary` لا تقل عن 110 كلمات.
- كل `chapters[].summary` 50–90 كلمة.
- كل قسم 90–150 كلمة.
- كل `figures[].note` 50–90 كلمة.
- مجموع الملف الواحد لا يقل عن 2,200 حرف عربي.
- 8 أحداث زمنية على الأقل، بتواريخ صحيحة أو تقريبية موسومة.
- 3 مصادر حقيقية قابلة للتحقق، بروابط تعمل.
- روابط `connections` تستخدم فقط المعرفات الموجودة في القائمة المسموحة.
- لا تكرار لأي `id`.

## التحقق
بعد الكتابة شغّل:
```bash
node --check history-entities-X.js
```
وتأكد أن الملف يبدأ بـ `(() => {` وينتهي بـ `})();` وأن كل الأقواس مغلقة.
