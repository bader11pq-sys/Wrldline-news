# لماذا اختفت بعض الأخبار، وكيف صُحّح ذلك

## المشكلة

كانت لوحة التحرير تحفظ الخبر وتقول إنه نُشر، لكن الموقع العام يعرض صفحة الخطأ «هذا الخبر لم يعد منشوراً»، ويختفي الخبر من قائمة أحدث الأخبار.

السبب ليس الحذف ولا خطأ في الإدخال، بل بوابة النشر الآلية `private.wrldline_audience_decision()`. كُتبت هذه البوابة للأخبار المستوردة آليًا، وتسأل: هل المصدر معروف؟ هل اللغة عربية؟ هل الموضوع خبر صلب؟ هل هناك صلة إقليمية؟ ثم تضع الخبر في مسار `excluded` أو `leisure`، فلا يُبنى له صفحة عامة ولا يظهر في الأحدث.

المقالات التي كتبها المحرر بيده كانت تُعامل معاملة الخبر المستورد:

- عنوان قصير من 7 أحرف أو أقل ← `short_headline`.
- خانة المصدر فارغة ← `missing_source`.
- «WRLDLINE NEWS» لم تكن مسجلة في `source_policy` ← مصدر غير موثوق.
- خبر رياضي عربي ← `leisure`، بلا صفحة عامة.
- حفظ خبر عربي بينما لغة الواجهة إنجليزية ← `lang='en'` ← `non_arabic_unvetted_source`.
- توليد آلي لا يعرف المصدر ← `blocked_source`.

وكانت `admin.html` تحفظ دون أن تفحص `audience_lane` بعد الحفظ، لذلك لم يظهر أي تحذير. أما محرر الموقع `site_editor` فكان يرفض الحفظ برسالة «Publication gate did not permit this story»، ولهذا نجح بعض النشر وفشل بعضه.

## ما تغيّر

1. الهجرة `supabase/migrations/20261125120000_editorial_publication_bypass.sql`:
   - تسجيل `wrldline news` و«هيئة التحرير» و`editorial desk` كمصادر تحريرية في `source_policy`.
   - دالة `public.wrldline_is_editorial(text)` للتعرف على المصدر التحريري.
   - تجاوز واضح في بداية قرار الجمهور: المحتوى التحريري البشري يذهب إلى `arabic`، أو `world` إذا كانت لغة الخبر إنجليزية، بسبب `human_editorial`. لا يُطبَّق عليه فحص العنوان القصير ولا المصدر ولا الصلة الإقليمية.
   - وسم الصفوف بـ `gate_version = 'gate-2'`، وإعادة تقييم الأخبار التحريرية السابقة عبر `update public.articles set title = title` ثم `wrldline_gate_backfill(null)`.
   - دالة `public.editor_publication_audit(integer)` لمدراء وهيئة التحرير، تعرض حالة الظهور وآخر 30 يومًا.
   - لا حذف لأي صف. التراجع: إعادة جسم الدالة السابق ثم `select public.wrldline_gate_backfill(null);`.

2. لوحة التحرير `admin.html` و`admin.js`:
   - خانة «حصري» مع حقل «أساس الحصرية» إلزامي عند تفعيلها.
   - بعد كل حفظ يُفحص `audience_lane` و`gate_reason`، وتظهر ملاحظة عربية إن كان الخبر لن يظهر، مع سبب واضح بدل الصمت.
   - لا يُرسل إشعار النشر إلا بعد التأكد من أن الخبر ظاهر فعلًا.

3. محرر الموقع `site-editor.js`: رسائل الخطأ تشرح البوابة بدقة، وحساب الكلمات صار مؤجلًا (300 مللي ثانية) بدل حسابه عند كل ضغطة.

4. منظم النص `editor-workspace.js`: عدّ الكلمات والتحقق من الحجم يعملان على الجزء الظاهر فقط، والحفظ المحلي مؤجل 1.2 ثانية ومحدود بـ400 ألف حرف، ما ينهي التعليق عند كتابة المقالات الطويلة.

5. مساعد التحرير `editorial-assist.js` و`supabase/functions/editorial-assist`:
   - فحص فوري بلا إنترنت: عنوان قصير أو مثير، فقرة واحدة طويلة، جمل أطول من 38 كلمة، حشو، مبني للمجهول، ترقيم لاتيني داخل نص عربي، غياب النسبة.
   - ثلاثة أزرار تحتاج نشر دالة الحافة: تحرير، تكثيف، اقتراح عناوين. لا يضيف المساعد وقائع أو أرقامًا أو اقتباسات، ويعيد ملاحظات بما يجب مراجعته بشريًا.

## خطوات التشغيل (مرة واحدة)

1. افتح Supabase ← SQL Editor ← New query، والصق كامل محتوى:
   `supabase/migrations/20261125120000_editorial_publication_bypass.sql`
   ثم Run. النتيجة المتوقعة آخر سطر `notify pgrst, 'reload schema'` بلا أخطاء.
2. تحقق سريعًا:
   ```sql
   select gate_version, audience_lane, gate_reason, count(*)
   from public.articles
   group by 1,2,3 order by 4 desc;
   ```
   يجب أن تظهر صفوف `gate-2` و`human_editorial`.
3. انشر دالة المساعد (اختياري، ويلزمه مفتاح مزود واحد على الأقل):
   ```bash
   supabase functions deploy editorial-assist
   supabase secrets set GROQ_API_KEY=...   # أو NVIDIA_API_KEY / GEMINI_API_KEY / OPENROUTER_API_KEY
   ```
   الدالة تتحقق من جلسة المحرر عبر `Authorization: Bearer <access_token>` وتقبل الدور `admin` أو `editor` فقط.
4. افتح `https://al-ghaib.us.ci/admin.html`، أعد التحميل بقوة (Cmd/Ctrl+Shift+R) لتجاوز نسخة مخبأة قديمة.

## طريقة النشر بعد الإصلاح

- من لوحة التحرير: اكتب العنوان، اختر القسم، اترك المصدر «WRLDLINE NEWS». سيظهر في الأحدث وفي القسم المختار.
- من واجهة الموقع بحساب أدمن: نفس الحقول داخل نافذة التحرير.
- «حصري»: فعّل الخانة واكتب أساس الحصرية. يظهر الخبر في الحصريات ويبقى في الأحدث لأنه نازل للتو.
- القسم واللغة: القسم يحدد مكان الظهور في صفحات الأقسام، واللغة العربية تذهب إلى الواجهة العربية. لا حاجة لتغيير لغة الواجهة إلى العربية قبل الحفظ بعد الآن، لكن الأفضل ضبط لغة الخبر نفسها.
