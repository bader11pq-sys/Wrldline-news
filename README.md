# WRLDLINE NEWS

منصة إخبارية عربية/إنجليزية مبنية كواجهة ويب ثابتة، وتقرأ المقالات من Supabase REST API.

## التشغيل
- افتح `index.html` عبر خادم ويب ثابت أو GitHub Pages.
- يعتمد عرض الأخبار على جدول `articles` وجدول `article_translations` في Supabase.
- مفاتيح Supabase المنشورة في الواجهة يجب أن تكون مفاتيح Publishable/Anon فقط، مع تفعيل سياسات RLS المناسبة.

## تحسينات الواجهة
- تصميم تحريري متجاوب للهواتف والحواسيب.
- تصنيف حسب القسم والدولة، ترتيب زمني، بحث، حفظ محلي، مظهر داكن، وتبديل لغة.
- إظهار رابط المصدر الأصلي وتاريخ النشر بدلاً من اختلاق نص كامل للخبر.
- معالجة أخطاء الشبكة، حالات التحميل، وتنقية النصوص قبل عرضها.

## تنبيه تشغيلي وأمني
لا تضع مفاتيح الخدمة السرية أو مفاتيح Gemini أو Telegram في ملفات الواجهة أو المستودع. استخدم GitHub Actions Secrets أو بيئة خادم خاصة. لا تُعرض أسعار أسواق ثابتة على أنها أسعار مباشرة؛ يلزم مزود بيانات مالي مرخص وتحديث موثق لذلك.

## تطبيق الويب والعمل دون اتصال
- يدعم الموقع التثبيت كتطبيق ويب (PWA) من المتصفحات والأجهزة المتوافقة.
- يخزّن عامل الخدمة ملفات واجهة الموقع وصفحة الحساب محلياً لتسريع الفتح وإتاحة غلاف التطبيق دون اتصال.
- يتم تحديث ذاكرة التطبيق المؤقتة وتنظيف الإصدارات القديمة تلقائياً.
- الأخبار وبيانات الحساب والدفع تحتاج اتصالاً بالإنترنت؛ لا يتم تخزين بيانات Supabase أو جلسات الدفع في ذاكرة Service Worker.
