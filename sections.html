كيف تُبنى هذه الخريطة؟How this map is built

مصدر واحد لخريطة الأقسام يغذّي هذه الصفحة وشريط التنقّل وصفحات الأقسام، لذا تظهر الشجرة نفسها بالعربية والإنجليزية. تُحوَّل الروابط القديمة مثل /section/energy و/section/ai إلى القسم الذي يغطيها بدل أن تصبح أقساماً مكرّرة.A single section registry feeds this page, the navigation and the section pages, so the same tree appears in Arabic and English. Legacy links such as /section/energy and /section/ai redirect to the desk that covers them instead of becoming duplicate sections.
